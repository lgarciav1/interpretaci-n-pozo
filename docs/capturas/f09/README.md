# F09 · Pegar topes desde una planilla

Panel izquierdo, sección **Zonas**, botón **Pegar topes**: pegar (o cargar .csv/.xlsx) una tabla nombre–tope(–base),
ver la vista previa con los problemas por fila y crear las zonas (reemplazar o agregar). Un solo Ctrl+Z las deshace.

[Claro](pegar-topes-claro.png) · [Oscuro](pegar-topes-oscuro.png), 1366 × 768. La tabla de la captura trae un solape
(error, bloquea) y un hueco (aviso). Guion: `scripts/qa/pegar-topes.cjs` (con `npm run dev` levantado).
