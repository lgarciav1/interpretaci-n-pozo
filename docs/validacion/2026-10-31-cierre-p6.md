# P6 — Primer método ambiental específico y reproducible

Fecha: 2026-10-31. Base `13f026a94bcdd8c3243b8ce4979a3b0b469d0fd7` (#56), rama apilada sin integrar main. [Contrato ADR 0050](../decisiones/0050-primer-metodo-ambiental-mgt.md).

## Puerta original y resultado

| Requisito del masterplan P6 | Resultado verificable |
|---|---|
| Catálogo ambiental por herramienta | P6a conserva las seis familias no ejecutables; el método MGT tiene definición, condiciones y aceptación propias. |
| Herramienta concreta y referencia | LDEO MGT, GR total calibrado; artículo completo, ecuaciones 2–4 y ficha original LDEO leídos. El dato de presión se restringe al menor límite de las fuentes: 10000 psi. |
| Magnitudes/unidades y dominio | GR gAPI; caliper longitud convertible a in; posición/agua de mar/pozo abierto conocidos; guardas numéricas y condiciones máximas explícitas, sin presentarlas como rango experimental certificado. |
| Casos independientes | Diez resultados numéricos literales, dos posiciones × cinco diámetros, calculados con Python Decimal(50) sin importar el evaluador. Son matemáticos sintéticos, no ensayos de campo. Caso documental de posición desconocida en el informe LDEO: debe bloquearse. |
| Límites, nulos e incertidumbre | Rechazo fuera de guardas y de condiciones incompatibles; NaN con QC1/QC128; QC64 para salida corregida. Incertidumbre no publicada se declara como limitación, no se inventa un intervalo. |
| Efectos/compatibilidad/estado previo | Modelo confirmado, datum y procesado revisados; referencia explícita de GR sin corrección de pozo; efectos previos o desconocidos bloquean. No se combina silenciosamente con preparación de GR/caliper. |
| Evaluación, preview y aceptación | Evaluador puro en coordinador compartido, cancelación/memoria/cache; preview aislado, Project intacto y fuente GR elegible antes de aceptar; una receta de historial. |
| Procedencia, persistencia y consumidor | Ledger versionado, archivos/snapshots, fuentes/visor, exportación de datos/QC/manifiesto e informe; desactivar/reactivar/retirar recupera originales. |

La puerta no cambia: se entrega la implementación del primer modelo específico, su contraste con una referencia y casos independientes; permanecen explícitas sus limitaciones. No se certifica un intervalo de campo ni el TP. Las demás familias continúan bloqueadas; no se agrega una fórmula universal para satisfacer el rótulo de fase.

## Pruebas automáticas

Suite completa: **2877 pruebas, 169 archivos**, sin fallos (139,21 s). Tras el último endurecimiento del rechazo de efectos ambientales previos: **27 pruebas / 2 archivos**, typecheck y build aprobados. El ajuste está cubierto por los casos de adquisición del método.


Diecisiete pruebas nuevas en `mgt-environment.test.ts`: ambas posiciones/cinco casos, dominio/NaN/GR negativo, condiciones y referencias, dato de adquisición/datum desde desconocido, ausencia de doble corrección, motor/cliente reales, QC y linaje, in/cm/m/ft equivalentes, bloqueo de composición, no-op/aplicar una sola vez, invalidación por proyecto/caliper/adquisición, descendientes bloqueados sin fallback, undo/redo/archivo/snapshots, desactivar/reactivar/retirar, versión futura o campo inesperado, cancelación cooperativa sin resultado parcial y presupuesto de memoria. CSV/LAS/xlsx incorporan manifiesto y se prueba el informe. Apagar la herramienta de caliper bloquea la fuente GR preparada.

Fixtures y generador: [valores literales](../../tests/fixtures/mgt-known.json), [Python independiente](../../scripts/qa/mgt-reference.py), [proyecto sintético](../../tests/fixtures/mgt.ts). Las referencias y modelos QA no se hacen pasar por condiciones del pozo real.

El [chequeo de compatibilidad](../../scripts/qa/mgt-compat.mjs) ejecuta el validador real de P6a, commit `25f9dd2`: acepta una máscara anterior y rechaza preparación esquema 5 explícitamente. El proyecto conserva v7 y adquisición 1; solo el nuevo método usa preparación 5. No se promete que una app anterior ejecute MGT ni se elimina la receta al abrirla. El temporal de compatibilidad se protege y elimina al terminar.

## Navegador y cálculo conocido

Chromium, HTML de producción por HTTP local, 1366×900. Dataset sintético: 51 muestras, 46 corregidas, cuatro fuera de dominio/sin caliper y una faltante original. Para GR=100 gAPI y diámetro 8,5 in, centrado, el resultado es **104,5319 gAPI**; la tabla conserva original, corregida, diferencia y motivo/QC. Vsh promedio cambia **0,2930 (n=50) → 0,3325 (n=46)**; los recuentos se muestran para no ocultar que cambió el soporte. PHIE/Sw importados siguen **0,2/0,3**. Reservorio/pay exactos del módulo de sensibilidad: **49 → 39 m** en este proyecto QA.

Se prueban modelo desconocido y efecto de pozo ya aplicado bloqueados; configuración explícita/decimales; preview sin solicitudes al motor principal; invalidación al editar y Project idéntico al cancelar; aceptación sin cambiar parámetros/cutoffs, blobs o revisiones originales; undo/redo exactos; ZIP con LAS/manifiesto/QC; desactivar/reactivar sin multiplicar de nuevo; otro navegador recupera referencias; modificar posición y restaurar snapshot recupera la receta anterior; retirar vuelve al original. Offline sin Worker/SubtleCrypto previsualiza y aplica el mismo modelo/condiciones. El recorrido adicional parte con adquisición y datum desconocidos, los registra desde el editor con confirmación global y alcanza un preview válido. No se habilita el método solo por seleccionar la familia.

## Reproducción

```sh
npm ci
python scripts/qa/mgt-reference.py
git diff -- tests/fixtures/mgt-known.json
npm run typecheck
npm test -- --maxWorkers=1
npm run build
node scripts/qa/mgt-seed.mjs /tmp/mgt-seed
python -m http.server 4178 --directory dist
# Otra terminal, con Playwright Python y Chromium:
python scripts/qa/mgt.py --seed /tmp/mgt-seed --output /tmp/mgt-browser
node scripts/qa/mgt-compat.mjs /tmp/mgt-browser
```

El chequeo del lector anterior necesita el objeto Git `25f9dd2`. No se copian cartas/datasets/PDF en el repositorio; referencias y restricciones se conservan en definición/ledger. El TP permanece bloqueado hasta confirmar su herramienta y condiciones. La validación real de entrega y métodos adicionales siguen en P7/P8. No se repite toda la matriz visual/DPR/temas ni benchmark; offline se verifica tras cargar por HTTP y cortar red, no por file://. Main queda intacto y los PRs apilados abiertos para revisión.
