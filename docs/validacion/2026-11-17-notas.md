# F05 — Notas ancladas a profundidad

Base: `main`, `efe8895` (F07). Rama: `codex/f05-notas-profundidad`.

## Alcance

Notas puntuales o por intervalo, editor/listado desde el menú contextual del perfil, movimiento por arrastre y
teclado, historial, guardado y snapshots, figuras y tabla del informe. No cambia cálculos ni fuentes científicas.
Contrato: [0076](../decisiones/0076-notas-profundidad.md).

## Verificaciones

- `npm run typecheck` y `npm run build`: aprobados. El build contiene un único `dist/index.html`.
- `tests/notes.test.ts`: operaciones, validación, conservación del espesor en los extremos, ausencia de recálculo,
  deshacer/rehacer, snapshots, reapertura v6/v7 con y sin notas, saneamiento y escape de texto en informe.
- `tests/figures/notes.test.ts`: perfil del TP a SVG con notas de punto/tramo y texto multilineal, XML válido y texto
  escapado. PNG y SVG usan la misma superposición de canvas del renderer de figuras.
- Pruebas nuevas: 5 aprobadas. No se agregan tests de petrofísica porque las notas no realizan cálculos.

- Suite completa: `npm test -- --maxWorkers=2 --testTimeout=30000`: 229 archivos, 3.741 casos;
  3.739 aprobados y dos fallos exclusivamente de tiempo (cutoff completo 25,32 ms frente a 20 ms;
  sumario 93,09 ms frente a 60 ms), con Chromium de QA en paralelo. Se repitieron ambos archivos y los dos
  archivos nuevos sin navegador, con `--maxWorkers=1 --testTimeout=30000`: **25/25 aprobados**.
  No se modificaron los umbrales ni los cálculos. El intento inicial con timeout por defecto se interrumpió
  tras observar timeouts bajo la carga de build/typecheck/navegador; la ejecución completa es la indicada arriba.

## Navegador

`node scripts/qa/notas.cjs` intenta abrir el HTML construido por `file://`: este Chromium administrado devuelve
`ERR_BLOCKED_BY_ADMINISTRATOR` antes de cargar la aplicación. No se modificó la política del navegador.
La alternativa reproducible es servir `dist` localmente y ejecutar
`QA_URL=http://localhost:4173 node scripts/qa/notas.cjs`. El script desconecta la red después de cargar el HTML;
para la recarga HTTP habilita la red solo durante la navegación y vuelve a desconectarla.

El recorrido HTTP con el mismo HTML construido aprobó: TP real, creación de nota puntual e intervalo,
movimiento con flechas y arrastre real del puntero, deshacer, edición, borrado, restauración tras recarga
mediante IndexedDB. Capturas revisadas visualmente a 1366×768 en
[claro](../capturas/notas/light.png) y [oscuro](../capturas/notas/dark.png), usando la paleta para cambiar el tema.
