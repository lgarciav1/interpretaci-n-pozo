# F22 — Torneo de modelos contra corona

Base `main` actualizado, commit `65e0089`; rama `feat/f22-torneo-corona`. F22 figuraba pendiente antes de comenzar. ADR [0078](../decisiones/0078-torneo-modelos-corona.md) escrito antes del código. Autor Lucas <lgarciav@fi.uba.ar>.

## Alcance y límites científicos

75 combinaciones de cinco Vsh, cinco PHIT explícitos y tres Sw. Parámetros restantes, fuentes preparadas y recetas se conservan; no hay ajuste automático ni ganadora integral. La comparación de φ usa plugs incluidos con MD alineada explícitamente, unidades convertidas a v/v y pares comunes soportados. El TP permite evaluar φ; Sw–RI de desaturación no valida SW in situ y DRX composicional no es Vsh volumétrico. Esas variables aparecen no evaluables. Toda selección es exploratoria: ajustes previos pueden ser desconocidos y seleccionar con los mismos plugs introduce optimismo.

Evidencia numérica y sintéticos en [modelo](2026-11-17-f22-modelo.md); recálculo y hallazgos en [revisión independiente](2026-11-17-f22-revision.md). Los cinco RMSE de φ del TP coinciden con el recálculo escalar Python independiente a aproximadamente 1e−17. No se usa error de ajuste como validación independiente.

## Navegador

Comando reproducible `node scripts/qa/torneo.cjs`: Chromium administrado bloquea `file:///workspace/interpretacion/dist/index.html` con `net::ERR_BLOCKED_BY_ADMINISTRATOR` y «Your organization doesn’t allow you to view this site». No se acredita apertura por doble clic; la autorización de F20 no se extiende a F22. Edge y Firefox no verificados.

Alternativa: `python -m http.server 4173 --directory dist`, luego `QA_URL=http://127.0.0.1:4173 node scripts/qa/torneo.cjs`. El guion deshabilita red después de cargar el HTML y usa datos TP embebidos; registra duración, recorre tabla/aplicación/deshacer y captura claro/oscuro a 1366×768. Esta prueba HTTP se distingue de la apertura file:// pendiente.

Primer recorrido: cargó 151 referencias y siguió calculando al vencer una espera de 15 segundos. No se atribuyó aprobación al rendimiento; se añadió ejecución selectiva de dependencias sobre el plan completo sin alterar fuentes. Evidencia final de repetición y suite se agrega al concluir las verificaciones.

## Entrega

F22 permanece en revisión. El PR debe quedar en borrador mientras falte la apertura local obligatoria, sin iniciar F21 ni otra función.
